# Phase C Round 1 (mid-phase) Summary

**Trigger:** C.1.1 through C.3.4 landed (XSD additivity + Schema model + DefaultPlatform SPI + MysqlPlatform DDL + PgsqlPlatform DDL + SqlitePlatform reject + JsonbOperator).

**Status:** PASS-WITH-WAIVERS.

## Lens — Architecture
`CheckConstraint` mirrors the `Index`/`Unique` shape: extends `MappingModel`, `setupObject()` reads XML attributes via `loadMapping`, auto-naming uses md5(expression)[:8] consistent with `Index::doNaming()`. Column-scoped `<check>` is sugar handled in `SchemaReader` — flattens to `Table::addCheckConstraint()`. Clean.

`PlatformInterface` gains three boolean SPI methods (`supportsGeneratedColumns/InvisibleColumns/CheckConstraints`) plus `getCheckConstraintDDL`. `DefaultPlatform` defaults supports* false and `getCheckConstraintDDL` throws — concrete platforms (MySQL/PG/SQLite) all override. Tier 1 surface (`Propel\Runtime\*`) untouched.

## Lens — BC
XSD additivity proven by `tools/xsd-additivity-check.php` (12 fixtures validated, 0 failed). Every existing `tests/Fixtures/**/schema.xml` re-validates against the new XSD. `database.xsd` changes: 5 enumeration entries on `default_datatypes`, 3 optional attributes on `<column>` (`generated`, `expression`, `invisible`), 1 new optional element `<check>` on `<table>` and `<column>`, 1 new complexType `checkConstraint`. All `use="optional"` or `minOccurs="0"`. No enumeration values removed; no types tightened.

The PG `serial` → `IDENTITY` switch is a behavior change visible in DDL output. The `<vendor type="pgsql"><parameter name="legacy-serial" value="true"/>` runway is in place. 10 PgsqlPlatformTest assertions updated from `serial` to `INTEGER GENERATED BY DEFAULT AS IDENTITY` — these are SELF-tests of platform DDL emission, not Tier 1 / Tier 2 surface.

## Lens — DBA
- **MySQL 8 / MariaDB 10.5+:** `GENERATED ALWAYS AS (expr) {VIRTUAL|STORED}` syntax matches reference grammar. `INVISIBLE` keyword positioned correctly (after AUTO_INCREMENT, before COMMENT). `CONSTRAINT name CHECK (expr) [NOT ENFORCED]` matches MySQL 8.0.16+ grammar.
- **PostgreSQL 14+:** `GENERATED ALWAYS AS (expr) STORED` matches. `GENERATED BY DEFAULT AS IDENTITY` is the modern PG 10+ standard. PG has no VIRTUAL — virtual=true falls back to STORED with a `trigger_deprecation` note.
- **SQLite:** Frozen — all three new features rejected with actionable error message pointing at `docs/MIGRATION-FROM-PRE-AI.md#sqlite-frozen-features`. JSON column passes through as TEXT affinity.
- **PK INVISIBLE rejection:** Column::loadMapping throws EngineException when `primaryKey=true` + `invisible=true`. MySQL/MariaDB enforce this at the engine; we reject early at model-load.
- **JSONB→JSON deprecation:** MySQL Domain maps JSONB → JSON natively. The MysqlPlatform initializeTypeMap installs the deprecation-prone fold; production codepath is a noop deprecation.

## Lens — Schema-migration safety
`<check>` insertion order preserved (insertion-ordered list on Table). Duplicate-name detection in `Table::addCheckConstraint()` throws `InvalidArgumentException`. Round-trip XML→model→XML for the new attributes is deterministic (verified via `TableCheckConstraintTest::testMixedTableAndColumnScoped`).

Reverse-engineered schemas re-load cleanly only after Group C.4 lands (mysql/pgsql parser migration to INFORMATION_SCHEMA). C.4 is the next group; this round predates it.
