# Tier 1 frozen public API surface (umbrella spec §3.1) plus Tier 2 deprecation-runway
# extension surfaces (§3.2). Snapshots in this directory are JSON dumps of method
# signatures + extends/implements + properties + class constants + @method PHPDoc
# methods. The CI gate (.github/workflows/quality-gates.yml job: signature-diff)
# regenerates and diffs against committed snapshots; any drift fails the gate
# unless paired with @deprecated annotations in the same diff.

# Generated bookstore Base classes are tracked separately by lint-generated +
# golden-file diff (see .github/workflows/quality-gates.yml).
